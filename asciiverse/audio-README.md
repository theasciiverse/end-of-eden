# Audio

The Asciiverse build ships these six sound effects, all released under
CC0 (upstream's assets/audio/README.md):

- damage_1.wav, damage_2.mp3, damage_3.mp3
- death_scream_1.wav
- game_over.mp3
- btn_deny.wav

Upstream credits the
[512 Sound Effects (8-bit style)](https://opengameart.org/content/512-sound-effects-8-bit-style)
pack by Juhani Junkala (CC0) among its sound sources.

They play in the Windows build; the Linux and macOS builds are silent.
